# 试过、没收的规则

想到一条古法、改进程序、跑回归不过关的，记在这里：想法与出处、改了哪里、回归数字、为什么不收。往后想到同样的点子，先看这一页，别重复试。

回归口径：

- 八字：`node scripts/bazi-cases.mjs`（《滴天髓阐微》《子平真诠》命例；写了用神的命造按 id 尾数 0、4、7 固定留出，只验收不调参）。岁运「同 / 近 / 反」指原书点名吉凶的大运、流年，程序判同、判平、判反。
- 六爻：`test/liuyao-cases.test.js`（原有 155 例）与 `test/liuyao-qianjin-cases.test.js`（千金赋 47 例，PR #70 起）。原有的不能退，千金赋的同档不能少、断反不能多。

收不收的标准：训练与留集都不变坏、净增是几造以上而不是一两造、规则本身有原文依据。只救一两造、或要靠留集造才看得出好处的，一律不收。

## 八字·旺衰

- **根逢遥冲**（年支冲日支、月支冲时支等不紧贴的冲克也给根打折，0.8 / 0.6 / 0.5 三档；任注「冲去禄神，其根已拔」）：岁运只改 458 一造（同 621 → 626、反 176 → 173），却把 256 由极强打到偏强，用神同 → 反，旺衰同 144 → 142。只救一造，不收。现行只算紧贴之冲（`baziStrength.js` 的 `chongAttackerOf`）。
- **月令被紧冲，得令打折**（巳被亥、午被子、卯被酉、寅被申，0.8 / 0.6 / 0.5）：训练集岁运、用神一处不变；变动全在留集（127、224、277：旺衰同 144 → 146、反 14 → 13，岁运同 +1）。这条是看 224「巳亥逢冲，破禄去火」想到的，224 本身是留集造，不算干净的验收；又与「衰神冲旺旺神发」相悖（月令多是旺神）。不收。

## 八字·岁运

- **运干坐库随天干**（#61 `kuRootOf`：甲辰、壬辰、辛丑、癸丑、丙戌、庚戌、乙未、丁未）：由 #62「大运地支四库按方论」（`fangOfYunZhi`：未作火、癸丑作水、甲辰作木）取代。合并模拟上岁运同 / 反 / 近：按方论 621 / 176 / 181，只坐库 623 / 182 / 173，两者叠加 624 / 178 / 176；运中六亲按方论最好。逐个加在按方论上的（壬辰、辛丑、丙戌、庚戌、乙未作木）变动都只在一两造、又多在留集，不收。
- **大运地支冲原局（衰神冲旺）**：三种近似都使岁运同数下降（621 → 613 / 601 / 620），不收。
- **一喜一忌的大运「以地支为重」**（干忌支喜按喜、干喜支忌按忌；原注「大运……故重地支」）：训练集同 536 → 600、反 148 → 191，留集同 85 → 98、反 28 → 32；「忌盖喜」仍参半的版本训练 586 / 182、留集 95 / 31。以「近」换「同」又多出不少反判。干忌支喜各组合原书吉:凶 = 支克干 29:19、干克支 17:10、支生干 16:7、干生支 7:5，都不到七成，仍作参半（`baziYearMarks.js` 的 `coverOf`）。
- **流年「重天干」**（原注「太岁譬所遇之人，故重天干」，干支一喜一忌时按天干）：训练集同 536 → 551、反 148 → 157，留集同 85 → 86、反 28 → 30；冲突的流年按干判对 16、判反 11，不收。
- **流年判平则随所行大运**（原注「太岁一至，休咎即显」）：原书点名的流年与其所在大运，书判 50 例里 47 例同吉同凶，可见任注说到的年份多是应运而发；但程序的大运本身约七成准，流年判平改随程序大运：同 +9、反 +6，不收。流年与大运程序判法不一时也看不出偏向（流年凶而运吉，书 3 吉 4 凶；流年吉而运凶，书 2 吉 0 凶）。

### 现状（2026-11-01）

岁运反判 176 处里，86 处集中在 32 造「反多于同」的命造——用神本身取错（从、化、顺局、遥冲、调候各一两造，没有共同的规律）；其余 90 处散在 50 造。用神取对的命造里，大运按现行规则：喜盖忌书吉 17、书凶 2，截脚书吉 6、书凶 18，两忌同气书吉 2、书凶 26，口径已稳。往后提准，要靠更多命例与逐造推敲的用神规则，不靠再调岁运的合成规则。
