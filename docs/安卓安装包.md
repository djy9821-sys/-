# 古书派安卓安装包

GitHub Actions 会把网站的同一份网页自动打成安卓安装包（`.github/workflows/android.yml`）。

## 下载与安装

- 预览版：`claude/**` 分支最新一次构建，含还没上线到网站的优化。
  https://github.com/djy9821-sys/-/releases/download/android-preview/gushupai.apk
- 正式版：`main` 的构建，合并上线后才有。
  https://github.com/djy9821-sys/-/releases/download/android/gushupai.apk

用手机浏览器打开下载地址，下载完点开安装；第一次会提示允许浏览器安装应用，选允许。
更新时下载新的 gushupai.apk 直接覆盖安装，命盘档案会保留。预览版和正式版是同一个应用，可以互相覆盖。
装好的应用每隔几小时会查一次 GitHub，有新版时底部提示「下载更新」（连不上 GitHub 就不提示）。

## 怎么做的

- Capacitor 7 外壳，网页文件（`dist`）装在手机里：断网也能排盘，不受网站缓存影响。
- Capacitor 只在 CI 里临时安装，不进 `package.json`。安卓工程每次由 `npx cap add android` 现生成，
  再由 `scripts/android/prepare.py` 定制：图标（取 `public/pwa-512x512.png`）、深色状态栏与启动画面、
  定位与相机权限（真太阳时定位、手势八卦，用到时才请求）、版本号（versionCode 取运行编号，只增不减）。
- `scripts/android/native-shell.js` 只打进安装包，补齐 WebView 与浏览器的差别：返回键先后退、到首页再按退到后台；
  `navigator.share` 换成系统分享面板；`<a download>` 的文件交给分享面板保存或发送；有新版时提示下载
  （`scripts/android/update-check.js`，读 Release 说明里的 versionCode）。网页代码不用为安卓改。
- targetSdk 暂用 34：35 起安卓 15 强制全面屏，网页还没做安卓的安全区适配。
- 签名钥匙在第一次构建时自动生成，存在草稿 Release「android-signing-key」里（草稿只有仓库管理者看得到）。
  不要删除或发布它：换了钥匙，手机上就不能覆盖安装，只能卸载重装，命盘档案会丢。

## 支线 AI 注意

`.github/workflows/android.yml` 和 `scripts/android/` 属于禁区，不要改。
