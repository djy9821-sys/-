# side-07 补录八字古赋与几篇常被引用的古书

先读 `docs/AI协作手册.md`、`src/data/classics/README.md`、`docs/tasks/side-06-jiaozheng.md` 的「通则」。

## 为什么有这张卡

主线核了两套八字课（云聪学易 65 讲、黄离论易 594 集）。讲课人引得最多的几篇古赋、几部古书，藏经阁里没有，引文对不了，只能拿网上的转载页当线索。把它们录进来，以后核验和批命都能直接引原文。清单和缘由记在 `docs/批命手册.md` 第六节。

只录古书的原文。今人的注解本、讲义（梁湘润、刘锦瀚等）有版权，一个字都不录。

## 通则

- **底本用影印本。** 每条对着扫描页录，`notes` 写扫描页码（PDF 页和书内卷页），文件的 `edition` 写清版本与来源。找不到影印本的那一篇先不做，在 PR 里说明，不要拿网页转载、白话本、校注本顶替。
- **原文照录。** 一句一条或一联一条，照底本的字，繁体转简体。底本明显的讹字照录，另写进 `doubts`，注明通行本作什么。不补字，不改字，不把两处的话拼成一句。
- **白话逐句直译**，自己写，不扩写，不加原文没有的断语和例子。原文里以贞淫贵贱论女命、断人夭亡的句子照录原文，白话如实直译，不添油加醋；这类条目的 `applies` 留空，不让它们出现在批命页上。
- 条目先标 `status: "draft"`。主线逐条复核后再改。
- 新书要在 `src/data/classics.js` 登记，篇目先后要排进 `shelf.js`，这两处由主线做。支线只交 JSON 文件，在 PR 说明里写清每个文件在原书的卷次和前后次序。
- 禁区照旧：`src/utils/**`、`src/App.jsx`、`test/golden`、CI、`package.json`、各种配置不碰；不新增依赖。每批跑 `node scripts/validate-data.mjs`、`npm test` 后再推送。一批一个分支、一个 PR。PR 的 base 由主线指定；没有指定时开草稿 PR，等主线回复，不要自己合并。
