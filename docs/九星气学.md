# 九星气学

入口 `#/jiuxing`。填一次姓名和生日（性别、常住城市可选），分六个页签：总览、运势、吉方位、相性、本命、依据。

## 算的是什么

| 内容 | 规则 |
|---|---|
| 年、月、日三柱 | 年支与年星立春当天换，月支与月星交节当天换，日星阳遁顺数、阴遁逆数（平常在甲子日换，每 4200 天有一回改在甲午日换）。 |
| 十二神兽 | 出生日的日柱所在旬（六旬）× 出生公历年的单双（立春前出生也照公历年）。 |
| 十二年的春夏秋冬 | 阳年生的逢旬首地支的年入春，阴年生的晚一年；之后每季三年。按立春那天换季，是本页的约定（书里只按年标季）。 |
| 吉方位 | 出行那天的年、月、日三张九宫盘上，同一方向都临调和星，且都不犯五黄杀、暗剑杀、水火杀。回程按返回那天、朝反方向另判。 |
| 相性 | 先看地支（三合为合、冲为不合），再看九星五行（生、比和、克，以及木火土金水的上下），最后看各自的神兽与对方地支。未满 6 岁看日柱，女未满 18、男未满 25 看月柱，之后看年柱。 |
| 守护本尊 | 按生年地支配八尊。 |

## 出处

- 十二神兽、十二年四季、择方只取三种凶方、相性只取三合与冲，出自唱田士始矢《スゴ運。》（2017），属近代日本九星气学一系，不是古籍里的成法。
- 八方的寓意取自该书的八方位表。守护本尊按生年配八尊是日本的“一代守本尊”；把八尊配到八方是按地支方位的传统配法，书里没有。
- 页面上的说明文字都是另写的，不是书里的原话。起伏线的形状量自书中六张图，只有相对高低，没有分数。

## 核对

- 九星历与该书所附 1939-02 至 2021-01 的逐日表（29,951 天，日本时间）逐日比对：日星、年星全同，月星只差 1964-09-07 一天（白露离午夜不到一分钟）。2021 年 2 月以后的日子书里没有印，由同一算法推出。
- 书里第五章的十七组择方日期与方向、书末九张盘的落星与凶方、图 19、33、34、36、37 的各张表，见 `test/jiuxing-calendar.test.js`、`test/jiuxing-person.test.js`。
- Codex 独立整理的二十个生日（240 个年度季次）见 `test/golden/jiuxing-beasts.json`。
- 书末查神兽的速查表有 53 格与实际日柱对不上，牵涉 218 个生日；程序按日柱取，遇到这样的生日在页面上注明。

## 没有做的

- 姓名不参与计算。
- 不推算彩票号码或中奖概率，书里也没有这样的办法。
- 不算时辰的九星盘，不算岁破、月破、日破。

## 文件

- `src/utils/jiuxing/core.js`：九星历与择方。`person.js`：神兽、四季、三柱、相性、守护本尊、方向扫描。`data.js`：节气、起伏线、速查表异格。`archiveProfiles.js`：从命盘档案取名单。
- `src/components/jiuxing/`：`JiuxingQixue.jsx` 管页头和挂载；`jiuxingView.js` 是不依赖 React 的视图，`jiuxingTemplate.js` 是骨架，`jiuxingTexts.js` 是说明文字和城市坐标，`jiuxing.css` 的规则都挂在 `.jx` 下。
- 姓名、生日不写进本机；已经存进命盘档案的人可以在页面上直接选。
