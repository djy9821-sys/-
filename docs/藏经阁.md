# 藏经阁

入口 `#/cangjing`，封面的第二扇门、首页「藏经阁」一栏、手机「更多」里都能进。把批命所依据的古籍摆上书架：原文与白话逐句对照，可以竖排读、搜字句、钤印收藏。批命页每条古籍下面的「在藏经阁里翻到这一条」，是在当前页面上盖一层藏经阁，合上就回到原处。

## 页面

| 层 | 地址 | 内容 |
|---|---|---|
| 书架 | `#/cangjing` | 按八字、紫微斗数、六爻分架；登记了还没录的书列在「待入藏」。上面是检索和「钤过印的」。 |
| 一本书 | `#/cangjing?b=ditian` | 题名、作者、底本、篇数条数、目录（按原书次第，分卷）。 |
| 展卷 | `#/cangjing?b=ditian&c=3` | 一篇的全部条目：原文、原注、白话、注、存疑。对照 / 只看原文 / 只看白话；横排 / 竖排（竖排只排原文，点一条下面出白话）。 |
| 翻到某一条 | `#/cangjing?e=qiongtong.jia.002` | 给分享和「翻到这一条」用：展开它所在的那一篇，那一条亮一下。地址随后改成 `b=…&c=…`。 |

- 每往里走一层记一步浏览器历史，手机返回键一层层退出来；「上一篇 / 下一篇」不新记历史。历史状态里带 `gushupaiDepth`，回首页时 App 一次退到底。
- 钤印只存在本机（`localStorage` 的 `gushupai-cangjing-stamps-v1`），最多 200 条。
- 检索：书名、篇名立刻出（只查目录）；原文和白话里的字句要先把三类书都取来，点「在全部原文和白话里找」才下载。

## 数据从哪来

- 全文就是 `src/data/classics/` 下的古籍文件，和批命页用的是同一份；翻开哪一类（八字 / 紫微 / 六爻）才下载哪一类。
- 书架和目录不等全文：`virtual:classics-catalog`（每本书的篇目与条数）和 `virtual:classics-total`（部、篇、条三个数）由 `vite.config.js` 里的插件在构建时按古籍文件现算（`scripts/lib/classicsCatalog.mjs`），不存成文件。录入、删改条目之后目录自然跟着变，不用另外生成什么。
- 篇目次第：文件名按拼音排不是书里的先后，`src/data/classics/shelf.js` 的 `DOC_ORDER` 按原书次第列出文件名；没列的排在后面（先按卷次，再按文件名）。新录的文件要在这里排上位置。
- 底本说明：`src/data/classics.js` 登记表里每本书的 `edition`，是写给读者的一两句话。各文件自己的 `edition` 记的是录入过程，不直接给读者看；一本书换了底本或加了来源，登记表这句要跟着改。
- 底本里电脑显示不了的字（Unicode 私用区）照旧显示成「□」，见 `src/data/classics/editorial.js`。

## 代码

| 文件 | 作用 |
|---|---|
| `src/data/classics/shelf.js` | 纯函数：排次第、建目录、取一篇的条目、地址参数、检索。只引登记表和 `sections.js`，别引 `schema.js`、`library.js`。 |
| `scripts/lib/classicsCatalog.mjs` | Node 端读古籍文件算目录；提供 Vite 插件。 |
| `src/components/cangjing/cangjingView.js` | 页面本体，不依赖 React：`mountCangjing(root, { catalog, loadEntries, initialQuery, history, scroller })`。 |
| `src/components/cangjing/CangjingGe.jsx` | 整页的藏经阁（页头 + 挂载）。 |
| `src/components/cangjing/CangjingReader.jsx` | 盖在批命页上的翻阅层：同一个视图，`history: false`，不改地址；打开时记一步历史，返回键只合上这一层。 |
| `src/components/common/ClassicsPanel.jsx` | 古籍条目卡片下面的「在藏经阁里翻到这一条」。翻阅层点了才下载，没下载成只在这一条下面提示。 |
| `src/components/WelcomeCover.jsx`、`cover/inkFluid.js` | 封面：两扇门、罗盘、水墨。 |

## 封面的水墨

`cover/inkFluid.js` 照 PavelDoGreat/WebGL-Fluid-Simulation（MIT，许可见 `public/licenses/WebGL-Fluid-Simulation-MIT.txt`）改写。几种情况不跑，封面用静态底色或停在当前画面：

- 浏览器不支持所需的 WebGL 功能，或用户设置了「减少动态效果」；
- 没有显卡加速、靠处理器硬算（渲染器名里带 SwiftShader、llvmpipe 等。自动化测试用的无头浏览器就是这种，所以测试里封面是静态底色）；
- 开头量帧率：一轮最多 24 帧或 0.8 秒，平均一帧超过 34 毫秒降一档，超过 60 毫秒（或降档后仍超过 40 毫秒）就停在当前画面。

## 字体

封面标题、书名用「GSP Kai Display」，原文用「GSP Kai Text」，都是霞鹜文楷裁出来的子集（SIL OFL 1.1，许可见 `public/licenses/LXGW-WenKai-OFL.txt`），放在 `src/assets/fonts/`，打包后进 `/assets`，离线也能用。正文字约 650 KB，读到原文时才下载。

- 重新裁：`python3 scripts/build-fonts.py <LXGWWenKai-Medium.ttf> <LXGWWenKai-Regular.ttf>`（要 fonttools；没装 Python 的 brotli 时借 Node 自带的压缩）。字体取自 https://github.com/lxgw/LxgwWenKai 。
- 看缺不缺字：`python3 scripts/build-fonts.py --check`。新录的原文里出现子集没有的字，会退回系统字体显示，不影响阅读；攒一批后重裁一次。
